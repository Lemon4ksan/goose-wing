## 0.1.0 (2026-11-28)


### ⚠ BREAKING CHANGES

* **pipeline:** harden server CORS/JWT/claims, client clock/TLS/WS/Digest, and CSPRNG fail-closed
* **security:** harden HPKE roles, CryptoJar, CSRF, Privacy Pass, SSRF, GCRA, and RFC 9421/9530
* **auth:** harden DPoP, PKCE, Digest SHA-512-256, JWT/JWE/JWK/JWKS, and OAuth
* **quic:** verify Retry tags, isolate 0-RTT keys, add KeyUpdate, and enforce AEAD limits
* **crypto:** harden core primitives, C shims, ML-KEM-768, and CT tooling
* **wing,core,http,net,server,client:** `core::get_query_param_fast` now returns `core::QueryParamMatch` instead of `(bool, bool)`, and downstream consumers of `wing` import `core` as `wing.core` rather than a separate package.
* **wing:** split Wave 3 packages (http, net, tls, client, server) into public and internal namespaces
* **server,fingerprint:** make header memoization opt-in, expand
* modernize all 19 modules with UFCS, errdefer rollback, and zero dead code
* **wire,client,server:** Request.headers, Response.headers, and Response.sent_headers now use HeaderMap instead of HeaderItem[..32]; HeaderItem and http/h2_framer.goose have been removed.
* Protocol-mandated RFC constants across HTTP/1.1, HTTP/2, HTTP/3, QUIC, TLS 1.3, WebSocket, and gRPC now reside exclusively in namespace rfc (rfc::*), while implementation-chosen tuning limits remain in wing and wire.
* **test:** migrate test framework to goose-lit and move baseline to .lit/
* **protocol:** Encapsulate HTTP/2, HTTP/3, QUIC, and low-level TLS wire framing, HPACK/QPACK codecs, and connection state machines into namespace internal to protect the future v1 public API stability. Public wing:: now exposes only high-level application abstractions (Client, Server, Session, HeaderMap, Request, Response, Router, WebSocket, TlsStream).
